# Backup

## What is backed up

| Item | Location on server |
|---|---|
| Database | container `anyvault_db` (volume `postgres_data`) |
| Media | `/var/www/any-vault/media` |
| Env file | `~/any_vault/.env` |

Static files and the frontend build are regenerated by `deploy.sh`.

## 1. Create backup on server

```bash
ssh -i ~/.ssh/key andrew_vasilev@81.26.180.68
```

```bash
TS=$(date +%Y-%m-%d_%H%M); B=~/backup_$TS; mkdir -p $B; cd $B
docker exec anyvault_db sh -c 'pg_dump -U "$POSTGRES_USER" -d "$POSTGRES_DB" -Fc' > db.dump
docker exec anyvault_db sh -c 'pg_dump -U "$POSTGRES_USER" -d "$POSTGRES_DB"' | gzip > db.sql.gz
tar czf media.tar.gz -C /var/www/any-vault media
cp ~/any_vault/.env env.backup
(cd ~/any_vault && git log -1 --oneline && git status --short) > git_state.txt
cd ~ && tar czf anyvault_backup_$TS.tar.gz backup_$TS
ls -lh ~/anyvault_backup_$TS.tar.gz
```

## 2. Download

```bash
scp -i ~/.ssh/key andrew_vasilev@81.26.180.68:anyvault_backup_<TS>.tar.gz D:/backups/any_vault/
tar xzf anyvault_backup_<TS>.tar.gz
```

Check the SQL dump is complete:

```bash
gzip -dc db.sql.gz | grep -c '^COPY public\.'   # number of tables
gzip -dc db.sql.gz | tail -3                    # should end without errors
```

## 3. Restore locally (PowerShell)

Local container: `any_vault-database-1`, user `postgres`, database `postgres`.

```powershell
docker cp .\db.dump any_vault-database-1:/tmp/db.dump
docker exec any_vault-database-1 pg_restore -U postgres -d postgres --clean --if-exists --no-owner --no-privileges /tmp/db.dump
docker exec any_vault-database-1 rm /tmp/db.dump
```

Do not pipe the dump through PowerShell (`<` is not supported, `|` corrupts binary data).

## 4. Restore on server

```bash
docker cp db.dump anyvault_db:/tmp/db.dump
docker exec anyvault_db sh -c 'pg_restore -U "$POSTGRES_USER" -d "$POSTGRES_DB" --clean --if-exists /tmp/db.dump && rm /tmp/db.dump'
tar xzf media.tar.gz -C /var/www/any-vault
cp env.backup ~/any_vault/.env
cd ~/any_vault && docker compose restart backend
```
